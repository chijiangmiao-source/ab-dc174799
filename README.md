# 超导量子芯片 · 纠错链复核台

每轮读出产生检测事件，校准员在浏览器中复核**最可能的纠错链**。系统不把每个事件
机械连向最近边界，而是在可编辑矩形码格上，把事件间与事件到边界的**最短链**归约为
**一般图最小权完美匹配**（Dijkstra + 加权 Blossom），以**精确整数**选出互不重复的
事件对链与边界链，使每个检测事件恰由一条链消去且总代价最小。

## 它解决什么

两个相邻事件各自到最近边界的距离可能都是 1（两条边界链合计 2），但它们彼此之间的
成对链只要 1。贪心的“逐事件就近连边界”会给出代价 2，全局最优是代价 1 的事件对。
本系统用最小权完美匹配避免这一类错误，并在结果页给出每条链的端点、逐边代价，以及
点选事件时“为什么成对 / 为什么连边界”的连接依据。

## 功能

- **可编辑矩形码格**：行列尺寸、正交相邻格间的正整数边代价、可作终点的边界格点、
  2–48 个按录入顺序编号的检测事件。
- **精确整数最优**：多源/单源 Dijkstra 求最短链；Galil/Edmonds primal-dual
  加权 Blossom 求一般图最小权完美匹配，全程 `bigint`，可承载超大整数代价。
- **稳定同成本结论**：同总成本时按事件录入顺序逐项比较链向量——
  **边界优先，随后另一端标识**（边界按格点编号排序、成对按另一端录入下标），
  以 `bigint` 位权微扰一次性决出规范解，不枚举配对。
- **结果页**：格图上绘制每条链（事件对链实线、边界链虚线 + 箭头），列出端点与
  逐边代价；点选事件查看连接依据；链卡片点击高亮。
- **错误定位**：重复事件、越界边界、非正边代价、无可达终点等，逐条中文提示并可
  点击在格图中定位。
- **Web Worker**：最短链 + 匹配全在后台线程；请求带版本号，**求解期间改动网格或
  取消任务时，旧结果不会覆盖新草稿或新结果**。
- **无贪心/枚举**：匹配代码有随机格网与暴力枚举的对照测试，Blossom 有数千随机
  可行图与暴力最优的对照测试。

## 算法要点

### 匹配图构造（2k 个节点）

- 节点 `0..k-1` 为检测事件；`k..2k-1` 为 k 个“边界槽位”虚节点；
- 事件—事件边 = 成对最短链；事件—槽位边 = 到最近边界的最短链；
- 槽位两两以权 0 相连：未使用的槽位自由配对。完美匹配中未被事件占用的槽位两两
  配对且代价为 0，于是边界链条数自动满足 `k − b` 为偶数，恰为物理可行条件。

### 同成本 tie-break

以基数 `Q = #边界 + k + 1` 的 `bigint` 位权表达链向量：事件位置 `i` 的序位，
边界链取所选边界序位（`0..#边界−1`），成对链取 `#边界 + 另一端录入下标`。
边界序位恒小于成对序位，故逐项比较时“边界优先”；权值 `主代价·Q^k + 链向量`
让匹配先最小化总代价、再按录入顺序逐项链向量稳定排序。

### 为什么需要一般图（非二分图）匹配

事件可以任意两两配对，匹配图不是二分图，存在奇环，必须收缩/扩张“花”（blossom）。
`src/solver/blossom.ts` 是 NetworkX 同款 Galil 1986 primal-dual 算法的 TypeScript
整数移植；`test/blossom.test.ts` 与 `test/solve.test.ts` 以暴力枚举为 oracle 做
大规模随机对照。

## 目录

```
src/solver/
  model.ts     # 矩形码格模型与结构校验（重复/越界/非正代价/事件数）
  blossom.ts   # 精确整数加权 Blossom：最大权匹配 + 最小权完美匹配
  solve.ts     # Dijkstra 最短链 → 匹配图归约 → tie-break → 链解码
  worker.ts    # Web Worker（版本号随请求往返）
src/ui/        # 状态版本防护、SVG 格图、侧栏检视、工具栏
server/        # 零依赖静态服务器（/healthz）
scripts/
  verify.mjs       # verify 一次性验收编排（可执行，退出码报告结果）
  verify-case.ts   # 第 1 步：“局部最近边界并非全局最优”断言
  fuzz.ts          # Blossom 随机暴力对照（开发用）
test/          # Blossom、求解管线、UI 状态竞态、jsdom 渲染测试
```

## 校验规则

| 情况 | 提示与定位 |
| --- | --- |
| 重复事件 | 标明第几录入项与第几项重复、格点号 |
| 越界边界 / 事件 | 标明编号与合法范围 |
| 非正边代价 | 标明相邻格与非法代价 |
| 无可达终点 | 定位到既到不了其他事件也到不了边界的事件 |
| 奇数事件且无边界等 | 说明成对链只能消去偶数个事件，无解 |
| 事件数不在 2–48 | 标明当前数量与合法区间 |
